## Core Patterns

- **Rhetorical Preflight Gate**: Rhetorical Preflight Protocol: evaluate task boundaries, downstream blast radius, and reviewer expectations before writing code.
- **Practical Application**: Preventing unrequested refactors and enforcing strict task boundaries.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
